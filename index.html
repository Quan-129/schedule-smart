Hướng dẫn Thêm tuần mới & Deploy qua Git
1

Tạo file Markdown mới

Tạo file schedules/tuan-37.md và nhập lịch học theo mẫu tương tự tuần 35.

2

Khai báo trong schedules/index.json

Thêm tên file vào danh sách để menu chọn tuần tự động hiển thị.

3

Đẩy lên Git (Push)

Chạy git add ., git commit -m "Thêm lịch tuần 37" và git push. GitHub Actions sẽ tự động deploy lên web sau 30 giây!
